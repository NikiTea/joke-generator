# 🎭 Генератор Анекдотов про Программистов

[![Python 3.6+](https://img.shields.io/badge/python-3.6+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Консольная программа на Python для поднятия настроения с коллекцией анекдотов про программистов! 😄

![Demo](https://img.shields.io/badge/demo-console-brightgreen)

## ✨ Особенности

- 🎨 **Цветной вывод** - красивое оформление в консоли
- 🎲 **Случайный выбор** - каждый раз новый анекдот
- ⚡ **Анимация текста** - эффект печатающейся машинки
- 📚 **10 анекдотов** в коллекции
- 🎯 **Интерактивное меню** - удобное управление
- 🎭 **ASCII-арт** - декоративные элементы

## 🚀 Быстрый старт

### Требования

- Python 3.6 или выше
- Терминал с поддержкой ANSI цветов (Windows Terminal, Linux/macOS терминалы)

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/joke-generator.git
cd joke-generator
```

2. Запустите программу:
```bash
python joke_generator.py
```

Или на Linux/macOS:
```bash
chmod +x joke_generator.py
./joke_generator.py
```

## 📖 Использование

После запуска программы вы увидите интерактивное меню:

```
🎯 Что будем делать?
  1 - Показать анекдот
  2 - Показать случайный анекдот с анимацией
  3 - Показать все анекдоты
  0 - Выход
```

### Команды

- **1** - Показать случайный анекдот с красивым оформлением
- **2** - Показать анекдот с эффектом анимации печати
- **3** - Показать все анекдоты из коллекции подряд
- **0** - Выйти из программы

## 🎨 Примеры

### Обычный вывод
```
┌──────────────────────────────────────────────────────────┐
│ Программист приходит домой с двумя батонами хлеба.       │
│ Жена спрашивает:                                         │
│ — Зачем два?                                             │
│ — Ты же сказала: купи батон хлеба, если будут яйца...   │
└──────────────────────────────────────────────────────────┘
```

### С анимацией
Текст печатается посимвольно, создавая эффект печатающейся машинки ⚡

## 🛠️ Технические детали

### Структура кода

- `Colors` - класс с ANSI цветовыми кодами
- `JOKES` - список анекдотов
- `print_colored()` - функция цветного вывода
- `animate_text()` - анимация печати текста
- `display_joke()` - вывод анекдота с рамкой
- `display_joke_animated()` - анимированный вывод
- `main()` - основной цикл программы

### ANSI цвета

Программа использует ANSI escape-коды для цветного вывода:
- 🔵 Синий - текст анекдотов
- 🟢 Зелёный - рамки и границы
- 🟡 Жёлтый - предупреждения и ASCII-арт
- 🟣 Фиолетовый - заголовки
- 🔴 Красный - ошибки
